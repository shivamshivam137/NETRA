# 🚦 NETRA — Frontend Application

Networked Engine for Traffic Recognition and Analytics (NETRA) Web Console.

For complete setup and run instructions, see [HOW_TO_RUN.md](../HOW_TO_RUN.md).

---

## ⚡ Quick Run

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your web browser.

---

## 🔑 Login
- Click **⚡ Quick Demo Login** on the login screen to access the Command Center without typing credentials.

---

## 🛠️ Available Scripts

- `npm run dev` — Starts Vite dev server with Hot Module Replacement (HMR)
- `npm run dev -- --host` — Runs dev server exposed on the local network
- `npm run build` — Compiles and optimizes assets into `dist/`
- `npm run preview` — Previews the production build locally
- `npm run lint` — Runs ESLint checks
